# Sk Jahid Ali - Portfolio

Static site: HTML, CSS and JavaScript. No build step.

## Run
Open `index.html` in a browser, or serve the folder: `python3 -m http.server 8000`.

## Files
- `index.html` page content
- `style.css` styles
- `three-scene.js` 3D hero (three.js r128 from cdnjs)
- `chat-and-effects.js` portfolio assistant and card effects
- `photo.jpg` profile photo

## Notes
- The portfolio assistant works on static hosting and answers common questions from a built-in set of facts; it does not call an AI model or require an API key. A real generative AI integration needs a backend API so credentials are not exposed in the browser.
- Replace the three "Sample" testimonials in `index.html`.
- Update the LinkedIn, Facebook and GitHub links with your exact profile URLs.
- Deploy free on GitHub Pages, Netlify or Cloudflare Pages.
